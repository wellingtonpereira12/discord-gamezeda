Som Surround 7.1 Ativo no Headset

O Google Chrome possui uma limitação do Windows e não consegue capturar o som da tela inteira quando o fone está operando em Surround 7.1 (8 canais) como no Logitech G HUB (Could not start audio source).

💡 Como resolver de vez:
1. Para som de jogos/vídeos na tela inteira: Abra o Logitech G HUB → seu G733 → Acústica → Desative "Habilitar Som Surround" (mudar para Estéreo). O Chrome capturará o áudio imediatamente!
2. Para vídeos do navegador/YouTube: Compartilhe a aba em "Guia do Chrome" (o som funciona 100% nativo).
3. Para transmitir sua tela em HD agora: Clique no botão abaixo!
